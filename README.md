# Flux

**Modern file sharing and management platform**

Flux is a personal file sharing solution forked from [Zipline](https://github.com/diced/zipline), enhanced with custom features and optimizations tailored for private deployments.

---

## About

This project is built on top of Zipline's robust foundation, with additional features and improvements:

- **Cloudflare Turnstile Integration** - Mandatory CAPTCHA protection on authentication endpoints
- **Public Home Page** - Displays the latest uploaded file for quick access
- **Enhanced Admin Features** - Additional administrative tools and endpoints
- **Improved File Storage Routing** - Hierarchical filesystem organization for better scalability
- **Extended API** - Custom endpoints for enhanced functionality
